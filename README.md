# How to play

Download /the_captcha_game.pptx from this repository, then just open it **with PowerPoint**

PowerPoint 2016 and newer should work, but this was tested on the latest release of Office365 Personal

**NOTE:** This slideshow uses some advanced features of PowerPoint, so it'll not work with other slide editors!

### Tested in

* Office365 - PowerPoint latest build
* LibreOffice Impress (playable, but misclicks make you automatically lose, so very unfair)
